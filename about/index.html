这是什么

武将收藏阁 是一个用 Hugo 构建、托管在 GitHub Pages 上的静态站点， 用来管理与展示我的三国杀武将牌收藏。源码私有维护，不对外公开。

每一名武将对应一个专有编号（如 WEI 001）——编号 = 势力前缀 + 三位序号， 按 魏 / 蜀 / 吴 / 群 / 神 五个主分区陈列，晋 / 西 / 魔 / 君 / 野 归入折叠的「其他」。 已收集的武将在卡片正面展示封面立绘，未收集的展示占位框；任一武将（无论是否收集） 只要有版本图鉴，都能点开灯箱查看其全部称号、扩展包与历年卡面。

数据模型

站点是数据驱动的——所有信息存在 data/*.yml，构建时由模板渲染成卡片网格：

  • 势力表（factions.yml）：决定分区顺序与配色。
  • 武将名册（generals.yml，roster）：完整的武将身份列表，描述「有哪些武将」， 与是否拥有无关。
  • 已收集注册表（collection.yml）：出现在此即视为已收集。每个编号下可记多个版本 （不同称号），每个版本挂多张真实卡面（进灯箱）；编号级封面单独存，只作卡片正面。
  • 版本图鉴（moegirl_versions.yml）：每名武将的全部称号 / 扩展包 / 年版卡面（图走萌娘 URL）， 灯箱据此展示完整图鉴并按注册表逐称号标「已收集 / 未收集」。
  • 扩展包归属（general_packs.yml）：该武将出现过的全部扩展包，平铺为灯箱里的标签。

数据是怎么来的

三个互补的图源，由 scripts/ 下的脚本抓取、归一、入库：

  • noname（推荐，可离线）：开源三国杀仓库，武将数据规整且自带卡面，用于建名册与补封面。
  • 萌娘百科（默认 roster 源）：从纯编号表抓取官方编号矩阵， 并解析版本图鉴与扩展包归属。
  • fandom：备用的武将总表与卡面来源。

怎么用

# 抓取 / 更新武将名册（默认萌娘百科纯编号表）
python scripts/fetch_roster.py

# 批量录入收藏状态（导出 → Excel 勾选 → 导入）
python scripts/checklist.py --export
python scripts/checklist.py --import

# 或用站内「登记」页按称号录入、下载长表 收藏清单.csv 后导入（含首次获得日期）
python scripts/checklist.py --import-long

# 手动登记卡面：默认进灯箱；--cover 设为编号封面（首页卡正面）
python scripts/add_image.py "WEI 001" ~/Downloads/曹操.jpg --title 魏武帝
python scripts/add_image.py "QUN 900" ~/Pictures/杨玉环.jpeg --cover

详见项目仓库（私有维护）的 README.md。
